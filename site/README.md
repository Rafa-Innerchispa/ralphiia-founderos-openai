# InnerChispa public-site proposal

This directory contains a static, bilingual-ready website proposal for `www.innerchispa.us`.

It is intentionally separate from production. Do not upload it to shared hosting until Rafael approves.

## Publication model

- `www.innerchispa.us`: stable official public site.
- `lab.innerchispa.us`: living lab for experimental demos and real-time/Astro-connected experiences.

## Safety notes

The site avoids private network details, sensitive credential references, diagnostic dumps, and unresolved infrastructure details. The architecture copy is intentionally sanitized for public reading.
