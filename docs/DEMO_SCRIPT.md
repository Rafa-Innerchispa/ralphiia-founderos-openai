# QuoteOps Demo Script

Target length: under three minutes. Use the isolated judge account for the recording; the private owner flow may use authorized real data.

1. In ChatGPT, connect the approved RalphiIA/QuoteOps MCP and say: “Abramos el proyecto FEMAR para rehabilitar o reemplazar el control de acceso.”
2. Show `quoteops_start_or_continue_mission` creating the mission and work item idempotently.
3. Attach a product photo and a supplier price-list PDF. Let ChatGPT read them and call `quoteops_record_extracted_evidence` with product/model, prices, page/region, confidence, and warnings.
4. Show the evidence as `needs_review`; confirm it as Rafael, then record the exact supplier offer. Explain that no value was invented.
5. Open the web case file and show the same task, evidence, costs, risks, questions, timeline, and packages A/B/C.
6. Select one package. Point out that supplier costs are visible internally but customer selling prices remain zero.
7. Enter the real selling prices, approve as Rafael, and open the generated PDF. Show that the PDF contains customer prices and excludes supplier costs.
8. Register delivery in the isolated judge account, then show the completed task and integration trace.

Do not claim GPT-5.6 as the application runtime. The verified GPT-5.6 evidence is this Codex development session, the commit history, README, and video.
